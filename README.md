# ৭ পাতা — বাংলা ডিজিটাল জ্ঞানভান্ডার

সাতটি জ্ঞানদিগন্ত, সবার জন্য উন্মুক্ত। প্রতিষ্ঠাতা অর্নব। স্ট্যাটিক সাইটটি GitHub Pages-এ `main` শাখার root থেকে প্রকাশিত হয়।

[সাইট দেখুন](https://7pata.github.io/)

## নতুন বই প্রকাশ করুন

1. পিডিএফ ফাইলটি `books/`-এ রাখুন। প্রচ্ছদ `assets/`-এ রাখুন, অথবা ডিফল্ট প্রচ্ছদের জন্য `cover` খালি রাখুন। ফাইলের বড়-ছোট হাতের অক্ষরসহ পথ মেলান।
2. `config.js`-এ `books` তালিকায় একটি রেকর্ড যোগ করুন। নিচেরটি কেবল কাঠামোর উদাহরণ।

```js
{
  id: 'your-book',
  title: 'বইয়ের বাংলা নাম',
  author: 'লেখকের নাম',
  categoryId: 'technology',
  subcategory: 'Python Programming',
  summary: 'বইটির সংক্ষিপ্ত বিবরণ।',
  cover: 'assets/your-book.svg',
  pdf: 'books/your-book.pdf',
  publicationDate: '',
  status: 'upcoming',
  featured: false,
  tags: ['বাংলা', 'Python']
}
```

3. `categoryId` এবং `subcategory`-তে `categories`-এর মান ব্যবহার করুন। বইয়ের প্রকাশের দিনে প্রকৃত `YYYY-MM-DD` তারিখ ও `status: 'published'` দিন। `readingMinutes` ঐচ্ছিক এবং যুক্তিসঙ্গত অনুমান থাকলে দিন। `draft` বই ক্যাটালগে দেখায় না। আসন্ন বইয়ের জন্য `upcoming` রাখুন। নতুন বইয়ের আইডি একবার বেছে নেওয়ার পর স্থির রাখুন।
4. PDF-টি সাইটে যাচাইযোগ্য হলে অনলাইনে পড়া ও ডাউনলোডের লিংক চালু হবে। বহিরাগত HTTPS পিডিএফের জন্য Pages origin-কে CORS দিয়ে `HEAD` ও `GET`-এর অনুমতি দিন। দ্রুত পড়ার জন্য byte ranges সমর্থন করুন। বড় PDF-এর প্রথম ধাপ PDF.js এবং হোস্টের range ক্ষমতার উপর নির্ভর করে। ফাইল অনুপস্থিত বা অপ্রাপ্য হলে “শীঘ্রই আসছে” দেখাবে।
5. Commit ও deploy করার পর বইটি ক্যাটালগ ও নিজস্ব `book.html?id=your-book` ঠিকানায় দেখা যাবে। Search ও category রেন্ডারের জন্য অন্য কোনো HTML এডিট দরকার নেই। ইন্ডেক্সযোগ্য প্রকাশিত বইয়ের লিংক চাইলে `sitemap.xml`-এ URL যোগ করুন।
6. `book.html`-এর ভিজিটে শিরোনাম, বিবরণ এবং canonical ঠিকানা বই অনুযায়ী বদলায়। Facebook-এর মতো JavaScript না চালানো crawler ৭ পাতার সাধারণ শেয়ারিং প্রচ্ছদ পড়বে। সাইটটি বুক-নির্দিষ্ট social card আগে থেকে তৈরি করে না।

## সেটিংস

- `config.js`-এ বই, সাতটি বিভাগ, ফেসবুক পেজ এবং স্বেচ্ছা সহায়তার নম্বর রাখুন। JavaScript ছাড়া দেখানোর নম্বরগুলোও `index.html`-এ আছে। নম্বর বদলালে দুই জায়গায় একই অনুমোদিত নম্বর রাখুন। এখানে কোনো লেনদেন বা পেমেন্ট যাচাই হয় না।
- অনলাইন পাঠক শুধু দরকার হলে PDF.js লোড করে। পিডিএফ স্থানীয়ভাবে পড়ার অবস্থান মনে রাখে। রেন্ডার সম্ভব না হলে মূল পিডিএফ খোলা যায়।
- Analytics চালু করতে [ANALYTICS_SETUP.md](ANALYTICS_SETUP.md) দেখুন। PIN, OTP, analytics secret অথবা কোনো ব্যক্তিগত credential এই পাবলিক রিপোজিটরিতে দেবেন না।
- নাম ও Pages URL স্থানান্তরের পরিকল্পনা [MIGRATION.md](MIGRATION.md)-এ আছে।
