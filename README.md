# 7 Pata — বাংলা মুক্ত ই-বই ওয়েবসাইট

একটি সম্পূর্ণ স্ট্যাটিক, মোবাইল-ফ্রেন্ডলি বাংলা ওয়েবসাইট। কোনো ডেটাবেস, পেমেন্ট গেটওয়ে বা API key প্রয়োজন নেই।

## সাইট চালু করার আগে

`config.js` খুলুন।

1. `facebook`-এ আপনার ফেসবুক পেজের পূর্ণ URL দিন।
2. `payments.bkash`, `payments.nagad`, `payments.rocket`-এ আপনার অনুমোদিত গ্রহণকারী মোবাইল নম্বর দিন (শুধু ১১ সংখ্যার `01...` ফরম্যাট)। খালি রাখলে কপি বাটন বন্ধ থাকবে।
3. বইয়ের PDF ফাইলগুলো `books/` ফোল্ডারে রাখুন। `config.js`-এর সংশ্লিষ্ট বইয়ের `pdf`-এ পাথ দিন (যেমন `books/python.pdf`)। খালি থাকলে 'শীঘ্রই আসছে' দেখাবে।
4. বইয়ের টাইটেল, বিবরণ, বিষয়, ট্যাগ `config.js` থেকে পরিবর্তন করুন। নতুন বইয়ের জন্য `books` অ্যারেতে একটি নতুন অবজেক্ট যোগ করুন।
5. সাতটি বিভাগের নাম, আইকন ও বিবরণ `config.js`-এর `categories`-এ বদলান। বইয়ের `categoryId`-এ সংশ্লিষ্ট বিষয়ের `id` দিন।

উদাহরণ:

```javascript
payments: { bkash: '01XXXXXXXXX', nagad: '', rocket: '' }
// X-গুলোর জায়গায় আপনার নিজের প্রকৃত নম্বর দিন
// PDF আপলোডের পর বইয়ের তথ্যের ভিতরে:
pdf: 'books/python.pdf'
```

**কখনোই PIN, OTP, অ্যাকাউন্টের পাসওয়ার্ড বা অন্য কোনো গোপন তথ্য রিপোজিটরিতে দেবেন না।** Public GitHub repository-তে যেকেউ `config.js` দেখতে পারবেন। Wallet-প্রদানকারীর নিয়ম অনুযায়ী এই ধরনের স্বেচ্ছা সহায়তা গ্রহণ করার অনুমতি নিশ্চিত করুন।

## কীভাবে GitHub Pages-এ চালু করবেন

1. `7-pata/7-pata.github.io` রিপোজিটরির root-এ `index.html` এবং সাইটের অন্যান্য ফাইল রাখুন।
2. `Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save`।
3. সাইট: `https://7-pata.github.io/`।

## ফোল্ডার

- `index.html`: বাংলা ওয়েবসাইটের কাঠামো
- `styles.css`: পিংক-অনুপ্রাণিত রেসপনসিভ ডিজাইন
- `config.js`: বই, বিষয়, ফেসবুক লিংক, স্বেচ্ছা সহায়তার নম্বর
- `script.js`: সার্চ, বইয়ের বাটন, নম্বর কপি, মোবাইল মেনু
- `assets/`: কভার, ফেভিকন, শেয়ারিং প্রিভিউ
- `books/`: আপনার PDF ফাইল রাখার জায়গা

## গুরুত্বপূর্ণ তথ্য

- bKash-এর রঙে অনুপ্রাণিত হলেও এটি bKash-এর অফিসিয়াল সাইট নয় এবং কোনো অফিসিয়াল লোগো ব্যবহার করা হয়নি।
- GitHub Pages-এ ব্যান্ডউইথ ও ব্যবহারের নীতিমালা আছে; বেশি PDF ডাউনলোড হলে বিকল্প ফাইল হোস্টিং বিবেচনা করুন।
- এই সাইট নিজে অর্থ সংগ্রহ বা পেমেন্ট যাচাই করে না; নম্বর কপি করার ব্যবস্থা দেয় মাত্র।
- অনলাইন ফন্ট ব্যবহার করে; অফলাইনে বাংলা পড়ার জন্য ডিভাইসে বাংলা ফন্ট থাকা প্রয়োজন হতে পারে।
- ভিজিটর কাউন্টার নেই। প্রকৃত ট্রাফিক জানতে আলাদা অ্যানালিটিকস ব্যবস্থা যুক্ত করতে হবে।
